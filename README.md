# 🌐 Digital Business Card Generator

Create and customize your own digital business card with live preview, dark mode, downloadable image, and social media integration. This lightweight, responsive web app is built with vanilla HTML, CSS, and JavaScript — no frameworks or dependencies required.

---

## ✨ Features

- ✅ **Live Preview** as you type
- 🎨 **Multiple Color Schemes** – Classic, Modern, Minimal, or Custom
- 🌗 **Dark Mode Toggle**
- 👤 **Profile Picture Upload**
- 🔗 **Social Media Integration** – Twitter, Instagram, GitHub
- 🖼️ **Download Card** as PNG using HTML2Canvas
- 💾 **Save & Load Designs** from browser storage
- 📱 **Mobile-Responsive Design**
